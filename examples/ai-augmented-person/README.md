# Example: AI-augmented people

This example demonstrates how the same content master becomes two 20-page HTML experiences.

- **Source:** [Stanford CS / YouTube public talk](https://www.youtube.com/watch?v=BBl8bNJP6ds&list=PLoROMvodv4rOAe_DtQYOCKy6_x3irEYV1&index=2)
- **Topic:** How ordinary professionals can become AI-augmented rather than compete with AI on raw answer production.
- **Deep-reading version:** full explanations, examples, boundaries, and actions.
- **Visual review version:** one core claim plus one visual relationship per page for fast scanning and later recall.
- **Viewpoint analysis:** [Chinese analysis manuscript](analysis.zh-CN.md) with argument structure, boundaries, and practical relevance for ordinary people.

The example is an independent analysis and paraphrase for personal understanding and review. It does not reproduce a full transcript, replace the source video, or claim affiliation with the speaker, Stanford, or YouTube.

Open locally:

```bash
python3 ../../skills/video-to-insight-html/scripts/serve_previews.py \
  --text-dir ./text-version \
  --presentation-dir ./presentation-version
```
